# Support

## Getting Help

- **App not building?** See `README.md` Quick Start and `AGENTS.md` Hard-won gotchas.
- **Meeting Finder shows no results?** Check GPS + offline pack; verify feeds with `python tools/verify_resources.py`.
- **Bug report:** Open a GitHub issue with `flutter doctor --verbose` and steps to reproduce.

## Crisis Resources

Recovery for All is **not** a crisis service.

- US: Call or text **988** (Suicide and Crisis Lifeline)
- UK: Samaritans 116 123
- CA: Talk Suicide 1-833-456-4566

Use the in-app **SOS Sheet** (one-tap 988 / sponsor call / meeting finder).

## Security Issues

See `SECURITY.md` — email security@recoveryforall.app, not public issues.

We prioritize the roadmap in `blueprints/roadmap-v2.md`. Recovery-pathway-specific requests need a verified TSML/BMLT feed URL.
