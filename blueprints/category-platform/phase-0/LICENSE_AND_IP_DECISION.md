# Licensing, third-party rights and public disclosure — owner decision required

**Observed:** repository `LICENSE` is the MIT License with copyright `(c) 2026 Toxic Creationz`, while the prior root README described the application as proprietary and prohibited commercial redistribution. Both cannot be used simultaneously as an uncomplicated exclusive-distribution claim for the same covered material. This package changes explanatory README wording **without modifying LICENSE**.

## Mandatory provenance checklist

- [ ] Identify the legal copyright holder(s) and confirm whether `Toxic Creationz` is the intended attribution and has authority over every included work.
- [ ] Inspect past commits/releases and supplied copies: when, under what terms and to whom was MIT-licensed code distributed?
- [ ] Inventory third-party assets, literature, audio, illustrations, map tiles, feed content, model weights and patent/licensing restrictions separately from app code.
- [ ] Decide future distribution policy with qualified counsel. Changing license text now does not retroactively remove rights previously granted under MIT.
- [ ] Assess any desired patent claims with counsel before further public technical disclosure; filing rules vary by country and date.

## Options for the owner

**A — retain MIT**: consistent open-source distribution of covered code; monetize support, services or complementary assets only under their applicable licenses.\
**B — dual license where legally possible**: requires clear contributor rights and scope of each edition; cannot erase past MIT grants.\
**C — proprietary for future independently owned material**: prospective licensing path after chain-of-title review, clear separation of MIT-covered releases and third-party dependencies.\
**D — defer**: keep existing MIT LICENSE, avoid exclusive-IP claims and record decision as pending.

**Package default: D (defer).** Do not edit LICENSE, change copyright attribution, invent patent novelty or state exclusive redistribution rights without owner authorization. The root README should link the existing LICENSE and accurately describe its terms. Any new CI/documentation file in this overlay should not imply that a new license applies to existing MIT material.
